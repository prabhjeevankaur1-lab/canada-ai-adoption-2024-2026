# Canada AI Adoption 2024-2026

Analysis of artificial intelligence adoption by Canadian businesses and organizations.

## Data Source
Statistics Canada - AI adoption survey data (Table 33-10-0120-01)

## Project Structure

## Data Overview
- **67 industries** tracked
- **22 AI-related features** analyzed
- Features include: Machine Learning, NLP, Chatbots, LLM, Deep Learning, Computer Vision, RPA, and more

## Processing Steps
1. Data cleaning and normalization
2. Numeric conversion
3. Column name standardization
4. Removal of metadata rows
